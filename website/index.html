MASUK KE STUDIO ↗
01

TUTORIAL LOGIN

Masuk atau buat akun agar dashboard Jadibot dapat digunakan.

  1. Tekan MASUK KE STUDIO atau pilih menu Login.
  2. Masukkan username atau email dan password akunmu.
  3. Belum punya akun? Pilih tab DAFTAR, isi data, lalu buat akun.
  4. Setelah berhasil, kamu akan masuk ke Dashboard.
BUKA HALAMAN LOGIN
02

PAIRING NOMOR BOT

Hubungkan nomor WhatsApp yang ingin dijadikan bot melalui kode pairing.

  1. Dari Dashboard, tekan + NOMOR BARU atau buka menu Pairing.
  2. Masukkan nomor dengan format internasional, tanpa tanda +. Contoh: 628xxxxxxxxxx.
  3. Tekan MINTA PAIRING CODE, lalu gunakan tombol SALIN CODE bila diperlukan.
  4. Di WhatsApp: Perangkat tertaut → Tautkan perangkat → Tautkan dengan nomor telepon.
  5. Masukkan kode dan tunggu log menampilkan status connected.

Jangan bagikan kode pairing kepada siapa pun. Kode bersifat sementara.

03

SETTING BOT

Atur bot per session agar setiap nomor memiliki konfigurasi sendiri.

  1. Buka menu Settings setelah session sudah dibuat.
  2. Pilih session/nomor bot yang ingin diatur pada panel kiri.
  3. Sesuaikan nama bot, owner, prefix, mode, limit, dan fitur runtime.
  4. Atur media, backup, serta plugin sesuai kebutuhan session tersebut.
  5. Tekan SIMPAN & TERAPKAN untuk menerapkan perubahan.

Perubahan Settings hanya berlaku untuk session yang dipilih, bukan bot lain.

PAIR
PASANG BOT UTAMA
  1. Aktifkan bot utama di halaman Setting, lalu masukkan nomor dalam format internasional tanpa tanda plus pada formulir SIMPAN & MINTA CODE.
  2. Tunggu sampai kotak kode menampilkan 8 karakter (format XXXX-XXXX). Kode hanya hidup ±60 detik.
  3. Buka WhatsApp → Perangkat tertaut → Tautkan dengan nomor telepon, lalu masukkan kode.
  4. Kalau muncul Connection Failure atau Sesi telah logout, tekan HAPUS SESI BOT UTAMA lalu MINTA CODE LAGI.
Jangan menyalin nomor, pairing code, token, atau kredensial ke chat maupun feedback.
