# 🌊 Folder Imej Denia AI

Folder ini mengandungi fail imej Denia mengikut emosi & situasi perbualan.
Format yang disokong: `.jpg` / `.jpeg` / `.png`

---

## 📋 Senarai Nama Fail & 7 Emosi Denia

| Nama Fail | Emosi / Situasi | Penerangan |
|---|---|---|
| `denia_happy.jpg` | Gembira / Normal | Digunakan semasa bersembang ceria, santai, atau bergurau |
| `denia_love.jpg` | Sayang / Romantik | Digunakan khas untuk Kaizas (suami) semasa bersembang mesra |
| `denia_angry.jpg` | Marah / Merajuk | Digunakan bila diusik geram, merajuk comel, atau menolak godaan orang luar |
| `denia_shy.jpg` | Malu / Comel | Digunakan bila dapat pujian (cantik/comel) atau usikan romantik |
| `denia_sad.jpg` | Sedih / Risau | Digunakan bila ada rasa sedih, kecewa, broken, atau minta maaf |
| `denia_cool.jpg` | Tenang / Bijak | Digunakan semasa / selepas berjaya memuat turun video TikTok |
| `denia_wave.jpg` | Lambai / Salam | Digunakan untuk arahan `.denia on` dan `.denia off` (tidur/rehat) |

---

> 💡 **Nota Penting**:
> - Fail `denia_angry.jpg` boleh dimasukkan ke dalam folder ini untuk memaparkan reaksi muka marah/merajuk Denia.
> - Saiz imej yang disyorkan adalah **512x512** atau nisbah **1:1** agar paparan gambar kemas di WhatsApp.
